# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately through [GitHub's private vulnerability reporting](https://github.com/Wyrcan-io/gamr/security/advisories/new) with:

- the affected version or commit;
- clear reproduction steps;
- the impact and any suggested mitigation.

If that link is unavailable, contact the `Wyrcan-io` maintainers through the [organization profile](https://github.com/Wyrcan-io) before disclosing the issue publicly. Please allow reasonable time for a fix and coordinated disclosure.

## Scope

The CLI is intended to run locally. Do not paste secrets, tokens, or private repository contents into issue reports or game prompts.

Supported security fixes target the current npm release and the current default branch. Maintainers will acknowledge reports within seven days when a private channel is available and will coordinate a disclosure date based on impact and exploitability.
