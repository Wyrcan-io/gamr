# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately to the repository owner (for example, through GitHub's private vulnerability reporting) with:

- the affected version or commit;
- clear reproduction steps;
- the impact and any suggested mitigation.

If no private reporting channel is configured yet, contact the maintainer before disclosing the issue publicly. Please allow reasonable time for a fix and coordinated disclosure.

## Scope

The CLI is intended to run locally. Do not paste secrets, tokens, or private repository contents into issue reports or game prompts.
